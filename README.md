# Parallax Effect Adventure Website

A stunning adventure-themed website showcasing parallax scrolling effects with beautiful imagery of outdoor activities like biking, paragliding, and surfing.

## 🔗 Live Demo

Check out the live project: [Parallax Effect Adventure](https://ykbeladiya.github.io/Parallax-Effect/)

## ✨ Features

- Immersive parallax scrolling effects
- Responsive design
- Beautiful full-width background images
- Smooth transitions between sections
- Fixed background attachment for dramatic effect
- Clean and modern typography

## 🛠️ Technologies Used

- HTML5
- CSS3
  - Transform-style: preserve-3d
  - Perspective transformations
  - Fixed background attachments
  - Flexbox for layout

## 📱 Sections

1. **Hero Section**
   - Dynamic parallax background with overlaying text
   - Large, bold typography

2. **Adventure Activities**
   - Biking
   - Paragliding
   - Surfing
   - Each section features a parallax background with descriptive text

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/ykbeladiya/Parallax-Effect.git
```

2. Open `index.html` in your browser to view the project locally.

## 📝 Implementation Details

- Uses CSS perspective and transform-style properties for 3D effects
- Implements fixed background attachment for smooth parallax scrolling
- Utilizes z-index and positioning for layered visual effects
- Responsive text sizing and padding for better readability
